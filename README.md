# prince2-quizdemo

An independent, unofficial PRINCE2 exam practice prototype that consolidates question sources,
provides daily practice and mock exam modes, and highlights weak topics within each session.

## Quick start

Open `public/index.html` in a browser.

## Features

- Consolidated question bank with source references, topics, and ambiguity flags.
- Daily Practice mode (20 questions, immediate feedback).
- Mock Test mode (60 questions, 60-minute timer, end-of-test review).
- Session-based scoring and weak topic tracking.
- Mandatory disclaimer footer included on every page.
